## Décisions Q-03

1. **Source** : fichiers locaux versionnés ici. Pas de backend légal.
2. **Android** : les écrans restent sur « Document non encore validé » jusqu’à
   un visa juridique **et** une autorisation d’embarquer le corps dans
   Android Studio. Un brouillon produit n’est pas une politique Play.
3. **Identité éditeur** : absente du dépôt. Les mentions listent les champs
   à compléter ; aucun nom de société, RCCM, adresse ou e-mail n’a été inventé.
4. **Q-MED-01 / Q-MED-02** : le brouillon n’accorde pas le droit d’enregistrer
   une photo produit dans la galerie. Lot M3 reste **non** livré.

## Ce qui bloque encore le visa

- Raison sociale, siège, représentant, contact, hébergeur (mentions).
- Âge minimum d’inscription (non tranché dans les ADR).
- Conservation des commandes après effacement (ADR-0018, Q-19).
- Encaissement pour compte de vendeurs si Wave / paiement en ligne un jour
  (ADR-0012 : agrément BCEAO / COBAC / CBN).
- Canal support (`account_blocked`).

Le [dossier de visa](04-dossier-visa.md) liste les questions pour le
conseil. **Aucun visa n’a été émis** le 21 octobre 2026.
