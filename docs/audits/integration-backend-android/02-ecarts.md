# C. Rapport des écarts

Références : code des services sur la branche `claude/gifted-ritchie-t5ej2z` (= `main` @ `f1ea1ec` côté backend),
application Android (même branche, arbre de travail du 2026-10-22). « Corrigé » = corrigé dans l'arbre de travail,
**non commité** (consigne de la mission).

## Inventaire backend (synthèse des preuves)

- **Toutes les routes métier des 10 contrats existent dans le code** (aucune route documentée sans implémentation).
- Routes présentes dans le code mais absentes des contrats : uniquement des routes d'exploitation (`/health`, `/metrics`, `/api/v1/health*`), non exposées par la gateway.
- Aucun gestionnaire simulé ni `TODO` dans le code de production. Les fournisseurs SMS et email `log` sont réservés au développement.
- **Contrôles de propriété faits côté serveur partout** : l'utilisateur vient toujours du JWT, jamais du corps ou du chemin.
  - Une ressource d'un autre compte renvoie 404 : commande, adresse, panier, produit, envoi vidéo, notification.
  - Commentaire d'un autre compte : 403 en édition ; en suppression, seuls l'auteur et le propriétaire de la vidéo sont autorisés.
  - Session d'un autre compte : 404.
- Rôles : seules la modération (`/moderation/cases*`) et la suspension de boutique (`/admin/shops/*`) exigent MODERATOR ou ADMIN.
